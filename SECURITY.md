# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in `@vbyte/btc-dev`, please report it responsibly.

### How to Report

1. **Do not** open a public GitHub issue for security vulnerabilities
2. Email the maintainer directly at the address listed in the package.json or repository
3. Include a detailed description of the vulnerability
4. Provide steps to reproduce if possible
5. Allow reasonable time for a fix before public disclosure

### What to Include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Any suggested fixes (optional)

### Response Timeline

- **Acknowledgment**: Within 48 hours
- **Initial assessment**: Within 7 days
- **Fix timeline**: Depends on severity, typically 30-90 days

### Scope

This security policy covers:

- The `@vbyte/btc-dev` library code
- Security issues in direct dependencies that affect this library

Out of scope:

- Issues in applications built with this library
- Issues in transitive dependencies (report these to the respective maintainers)

## Security Best Practices

For guidance on securely using this library in your applications, see the [Security Best Practices section in the Guide](docs/GUIDE.md#security-best-practices).
